# Echorb Mobile — Android Releases

Official releases of the **Echorb Mobile** companion app for Android. Pair your phone with Echorb Desktop to see your instances, chat with them, mirror their terminals, and manage loops on the go.

**[Download the latest release →](https://github.com/virtuallifehub-del/echorb-mobile-releases/releases/latest)**

## Installing
1. On your phone, download the APK that matches your device from the latest release — **arm64-v8a** for most modern phones (choose this if unsure), **armeabi-v7a** for older 32-bit devices, **x86_64** for emulators.
2. Allow installs from your browser or file manager if prompted.
3. Open the APK to install, then scan the pairing QR from Echorb Desktop's **Settings → Mobile**.

Updates: the app checks for new releases once a day and shows a notice in its settings — or use "Check for updates" any time.
